# Mission clavier

**Mission clavier** est un jeu interactif en français pour apprendre et mémoriser les raccourcis clavier les plus utiles. À chaque mission, il faut choisir la bonne combinaison ou utiliser les raccourcis pour effectuer un exercice de manipulation de texte.

## Comment jouer

1. Ouvrez la page et cliquez sur **Start**.
2. Lisez la mission affichée.
3. Pour une question, appuyez sur le raccourci demandé ou saisissez-le au format `Ctrl+lettre`, puis validez. Sur Mac, la touche Commande (`⌘`) est également reconnue.
4. Pour un exercice, manipulez le texte dans les deux zones avec les raccourcis. Il faut obtenir le résultat demandé et utiliser les raccourcis attendus pour réussir.
5. Cliquez sur **Mission suivante** si la réponse est incorrecte. Après une réussite, la mission suivante démarre automatiquement.

Le jeu mélange les missions et les propose à nouveau lorsque la série est terminée. Le bouton **Recommencer** remet le score, la progression et l’historique des temps à zéro.

## Raccourcis et exercices

Les questions portent sur les commandes suivantes :

- `Ctrl+C` : copier
- `Ctrl+V` : coller
- `Ctrl+X` : couper
- `Ctrl+Z` : annuler
- `Ctrl+Y` : rétablir
- `Ctrl+A` : tout sélectionner
- `Ctrl+S` : enregistrer
- `Ctrl+F` : rechercher

Deux exercices pratiques complètent les questions : copier un texte entier dans une autre zone et remettre des phrases dans le bon ordre en les coupant et en les collant.

## Suivi de la partie

Le jeu affiche le score, le numéro de la mission et la progression dans la série. Un chronomètre mesure le temps consacré à chaque mission, et l’historique indique la durée des missions réussies ou à revoir.

## Lancer le site

Aucune installation ni dépendance n’est nécessaire. Téléchargez ou clonez le dépôt, puis ouvrez `index.html` dans un navigateur. Les fichiers HTML, CSS et JavaScript de l’application sont à conserver ensemble.
